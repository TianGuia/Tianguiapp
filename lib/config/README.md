# config/ · Ajustes generales

| Archivo | Qué contiene |
|---|---|
| `theme.dart` | Colores y tipografía de TianGuía, y el estilo de ventanas emergentes, menús y hojas inferiores (todos los `AlertDialog` lo toman de aquí) |
| `supabase_config.dart` | Dirección y llave pública para conectar con la base de datos |
| `estados.dart` | Nombres de los estados usados en la base de datos (abierto, cerrado…) |
| `enums.dart` | Otros valores fijos que la app comparte con la base de datos |
