# vendedor/ · Quien opera un puesto

**Módulo del diagrama:** Vendedor · **Requisitos:** RF-19 a RF-22

| Archivo | Para qué sirve |
|---|---|
| `vendedor.dart` | El rol de vendedor: activar el perfil, registrar horario y avisar ausencias. |
| `vendedor_tianguis.dart` | Une al vendedor con los tianguis donde trabaja (un vendedor puede estar en varios). |

Los **puestos, productos y ofertas** del vendedor están en `models/modelos.dart`
y `models/tratos.dart`.
