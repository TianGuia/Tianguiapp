# widgets/ · Piezas visuales reutilizables

Un widget es una pieza de pantalla (un botón, un fondo, un aviso) que se usa en
**varias pantallas**. Se escribe una vez aquí y se reutiliza.

| Archivo | Qué es |
|---|---|
| `pincel.dart` | Logo «TIANGUIA», botón amarillo, etiquetas y títulos del estilo de la marca |
| `fondo.dart` | El fondo azul con pinceladas de colores |
| `corazon.dart` | El corazón para guardar favoritos (RF-11) y la imagen de un puesto |
| `entradas.dart` | Reglas para los campos de texto (qué letras se permiten, límites) |
| `aviso_conexion.dart` | Avisa cuando no hay internet y los datos pueden estar viejos (RNF-5) |
| `cerrar_sesion.dart` | El botón de cerrar sesión (RF-04) |
| `enlaces_legales.dart` | Enlaces a términos y aviso de privacidad (RF-40) |
| `moderacion.dart` | Cuadros para reportar (RF-44) y bloquear (RF-38) |
| `ubicacion_producto.dart` | «¿Dónde lo encuentro?» en la ficha de un producto |
| `visita_flow.dart` | Escribir el código de visita y calificar (RF-41, 42) |
